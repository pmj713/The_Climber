# The Climber - 플레이 설명서

(2026-09-18 빌드 기준)

## 게임 목표

탑을 올라가며 몬스터를 처치하고, 경험치를 쌓아 캐릭터를 성장시켜 최대한 높은 층까지 도달하는 3D 탑뷰 로그라이크 액션 게임입니다.
(현재 빌드는 1~3층까지 구현되어 있습니다.)

## 조작법

| 입력 | 기능 |
|---|---|
| W / A / S / D | 이동 |
| 마우스 | 조준 (캐릭터가 마우스 방향을 바라봄) |
| 좌클릭 | 활 공격 |
| Space | 회피 / 구르기 (짧은 무적 시간 포함) |
| 우클릭 / E / Q | 장착한 액티브 스킬 발동 |
| I | 보유 스킬 창 열기 / 닫기 |
| G | 레벨업 선택지가 떠 있을 때, 게임을 멈추고 선택 화면 열기 |
| ESC | 일시정지 메뉴 |

## 전투

- 좌클릭으로 마우스 방향에 화살을 발사합니다.
- 근접 / 원거리 몬스터가 등장하며, 모든 몬스터는 공격 전에 예고 동작을 보여줍니다. 예고를 보고 `Space`로 회피하세요.
- 회피 중에는 짧은 시간 동안 무적입니다.

## 성장 시스템 (레벨업 & 스킬)

1. 몬스터를 처치하면 경험치를 얻습니다.
2. 레벨업하면 화면 하단에 안내 문구가 깜빡입니다 — `G`를 눌러 게임을 멈추고 스킬 3개 중 1개를 선택하세요 (숫자키 1/2/3 또는 마우스 클릭).
3. 스킬은 두 종류입니다.
   - **패시브 스킬**: 획득 즉시 키워드(관통 / 투사체 / 강격 / 공격속도 / 범위 / 버프) 능력치가 성장합니다.
   - **액티브 스킬** (예: 화살비, 헤이스트): 획득 후 `I`로 보유 스킬 창을 열어 **드래그해서 우클릭/E/Q 슬롯에 장착**해야 실제로 사용할 수 있습니다.
4. 같은 스킬을 여러 번 획득하면 그 스킬의 효과(범위, 지속시간 등)가 더 강해집니다.

## 화면 UI

- **좌상단**: 체력 바 / 경험치 바 / 레벨
- **우상단**: 보유 스킬 창 안내 (`[I] 보유 스킬`)
- **하단**: 레벨업 안내 문구, 장착한 액티브 스킬의 쿨타임 표시줄 (우클릭 / E / Q)
- **화면 중앙**: 레벨업 스킬 선택 창, 보유 스킬(장착/해제) 창, 일시정지 메뉴, 게임 오버 화면

## 사망 시

체력이 0이 되면 게임이 멈추고 결과 화면(도달 층수, 레벨)이 표시됩니다. **다시 시작** 버튼을 누르면 처음부터 새로운 런을 시작합니다.

## 목표 층 구성 (현재까지)

| 층 | 구성 |
|---|---|
| 1층 | 근접 몬스터만 (5파티) |
| 2층 | 근접 + 원거리 혼합 (5파티) |
| 3층 | 근접 + 원거리 혼합, 원거리 비중 증가 (5파티) |

층이 올라갈수록 몬스터의 체력과 공격력이 증가합니다.
